# Nyrva v0.3.0 — First Windows & Linux X11 MVP

**Release candidate. This release is kept as a draft until desktop acceptance is recorded.**

Nyrva is an edge-pinned desktop monitor for AI coding assistant usage and session activity, built on Rust and Tauri 2.

## Included in this candidate

- Windows NSIS installer (`.exe`).
- Linux X11 Debian package (`.deb`) and AppImage.
- Integrations for Claude Code, Codex, Cursor and Antigravity, subject to each provider's local installation, sign-in and state availability.
- The `nyrva-hook` helper for Claude Code in all three packages.
- CI build, test and package-content checks on Windows and Ubuntu 22.04.
- `SHA256SUMS` and readable license/credit notices accompanying the assets; those notices are also included inside the application packages.

## Validation status

The maintainer reported that a previous Windows CI build installed and ran successfully. That report is useful feedback, but it is **not** a complete smoke-test record for the newly generated packages in this release.

The full Windows checklist and the Linux X11 `.deb`/AppImage desktop acceptance remain pending. A successful automated build is not evidence of desktop acceptance. Record the exact package hashes, tested environments and results using `docs/SMOKE_TESTS.md` before publishing this draft as the accepted MVP.

## Requirements and limitations

Sign in through the providers' own applications. Nyrva reads their existing local credentials/state; installing the Claude hook explicitly changes its hook configuration.

Ubuntu 22.04 is the Linux CI baseline. Linux desktop support in this candidate is limited to X11; compatibility with each intended distribution must be tested rather than assumed.

Wayland, macOS, a redesigned interface, additional providers and automatic updates are outside this MVP. Packages are unsigned. SHA-256 verifies file integrity, not publisher identity; do not disable operating-system security protections to install them.
